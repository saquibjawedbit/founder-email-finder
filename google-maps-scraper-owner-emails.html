How to get owner emails from a Google Maps scraper list

Google Maps lists a website for most businesses but almost never an email or the owner's name. Take the websites from your Maps scrape and read each one for the owner and the contact email. With my tool you just give it the Apify dataset ID of your Maps run; it keeps the Maps name, phone, address and category on each row.

How to do it

  1. Run any Google Maps scraper on Apify (for example compass/crawler-google-places).
  2. Copy the run's dataset ID from its Storage tab.
  3. Open my tool, paste the ID into Google Maps dataset ID, press Start.
{ "datasetId": "YOUR_DATASET_ID", "onlyWithContacts": true }

Each website domain is read once, so chains and duplicate listings are not paid twice. Places with no website, or only a Facebook page, are skipped. To run it every time your Maps scrape finishes, add it under the Maps task's Integrations, with {"datasetId": "{{resource.defaultDatasetId}}"} as input.

Questions

Does it work with any Google Maps scraper?

It works with any Apify dataset that has a website column, such as compass/crawler-google-places or aurelix/google-maps-scraper.

Do I pay for places without a website?

No. They are skipped, and rows where nothing was found are free.

What does it cost?

$1.50 per 1,000 companies, and rows where nothing was found are free. Apify gives every account $5 of free credit each month, which covers about 3,333 companies.
